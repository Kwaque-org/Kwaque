# Security policy

## Supported versions

Kwaque has not published a production release. Until the first supported
release exists, only the current `main` branch receives security fixes and no
stability or response-time guarantee is made. This table must be replaced with
release lines when versioned support begins.

| Version | Supported |
|---|---|
| `main` pre-release | Yes, best effort |
| Unreleased local branches and old commits | No |

## Privately report a vulnerability

Use the repository's **Security → Report a vulnerability** form to open a
private GitHub security advisory. Include:

- affected revision and configuration;
- impact and the trust boundary crossed;
- minimal reproduction steps or a proof of concept;
- any known workaround; and
- whether the issue is already public.

Alternatively, email the maintainer at contact.vikramaditya33@gmail.com.

Do not open a public issue for an undisclosed vulnerability.

The maintainer aims to acknowledge a report within seven days, then reproduces
and triages it, coordinates a fix and disclosure, and credits the reporter if
requested. Fix and release timelines will be published once the project has a
staffed release process.
